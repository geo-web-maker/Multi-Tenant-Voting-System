## How to close #1 safely
One dashboard per card. For each: replace the inline button consts with `perf-btn` classes, delete the file from `LEGACY_BUTTON_FILES`, run both test modes, then look at every tab of that dashboard in both templates. Do the default-template look change deliberately and record it in `DEVIATIONS.md` (the default is no longer pixel-frozen for these panels).

### Static validation performed

- The migrated-kit/panel, Blueprint stylesheet uniqueness, allow-list, selector-class and perf-class-definition checks were mirrored using a Python static check: **pass**. There is exactly one `templates/blueprint/blueprint.css`; all `perf-*` classes used in static string class names have CSS definitions; no stale entries were found in `LEGACY_BUTTON_FILES`.
- `HEX_CEILING` is set to 294, matching the current count under the test's inclusion/exclusion rules.
